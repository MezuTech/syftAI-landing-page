This page covers **syftup.com**, the MezuTech website. The apps are separate
products with their own policies — see [Sift AI's privacy
policy](../apps/sift/privacy) for the one app that currently handles user data
through this domain.

## What this site collects

Nothing, directly. syftup.com is a set of static files. It has:

- **No analytics.** No Google Analytics, no Plausible, no pixels, no session recording.
- **No cookies.** Your light/dark preference is stored in your browser's own `localStorage` and never leaves your device.
- **No forms.** The contact links open your own email client; nothing is posted to a server here.
- **No third-party fonts or scripts.** The typefaces are served from this domain, so loading a page does not tell anyone else you visited.

## What the host sees

The site is served by **GitHub Pages**. Like any web host, GitHub receives the
IP address and browser user-agent of each request in order to serve it, and may
retain those in its own server logs under
[GitHub's privacy statement](https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement).
I do not have access to those logs and do not receive any report derived from
them.

## If you email me

Email sent to [hello@syftup.com](mailto:hello@syftup.com) is read by me and kept
only as long as it is useful to answer you. It is not added to a mailing list,
and there is no mailing list to be added to.

## The apps

The apps distributed by MezuTech — ScriptureFlow, StrideAI, LoveStory and Sift AI
— handle data on their own terms, described in each app and in its own policy.
This document does not cover them.
